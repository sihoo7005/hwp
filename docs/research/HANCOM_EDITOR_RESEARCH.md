# 한컴 한글 UI 및 직접 편집 방식 조사

- 조사 기준일: **2026-10-13**
- 목적: Android에서 페이지를 직접 편집하는 HWP 편집기를 설계할 때 참고할 한컴 한글의 UI와 수정 방식을 정리
- 대상: Windows 설치형 한글, 한컴오피스 모바일 한글, 한컴독스 앱·웹의 공식 공개 안내
- 자료: 한컴 공식 도움말·고객지원·릴리스 노트와 공식 화면 이미지

## 1. 조사 범위와 확인 수준

한컴의 편집기는 플랫폼별로 구분해야 한다. Windows 한글의 기능을 웹한글이나 모바일 앱의 기능으로 그대로 간주하지 않았다.

| 제품 | 이번 조사에서 확인한 것 | 확인하지 못한 것 |
| --- | --- | --- |
| Windows 설치형 **한글** | `hoffice130` 계열 공식 도움말의 기능·메뉴, 공식 편집 화면 이미지 | 프로그램을 직접 실행한 편집·저장 및 문서 호환성 시험 |
| **한컴오피스 모바일 한글** | 공식 Android 모바일 도움말의 메뉴, 터치 선택, 글자·표·개체 편집 절차 | 현재 Play 스토어 앱을 직접 실행한 화면과 기기별 입력 동작 |
| **한컴독스 웹한글** | HWP/HWPX 편집, 문서 관리·공유·저장 안내, 웹한글 릴리스 정보 | 로그인 후 편집 화면의 모든 버튼, 설치형 대비 세부 기능 차이 |
| **한컴독스 모바일 앱** | Android/iOS에서 보기·편집 제공, 공개 릴리스 정보 | 현행 앱의 전체 도구 구성과 기기별 터치·키보드 동작 |
| **휴대폰 브라우저의 웹한글** | 공식 지원 브라우저 목록 | 모바일 앱과의 기능 동등성, 좁은 화면에서의 편집 UI |

웹한글의 조사 시점 최신 공개 항목은 **v2.5.6.2 / 2026-09-01**, 한컴독스 모바일은 **v2.0.12 / 2026-07-14**다. 이는 공개 릴리스 노트 기준이며, 실제 접속 인스턴스의 빌드를 조회한 결과는 아니다. 같은 페이지의 웹서비스·웹오피스 버전 번호와 혼용하지 않는다. [공식 릴리스 노트][docs-release]

아래에서 **공식 확인**은 문서·이미지에서 확인했다는 뜻이다. 세부 지원 여부가 확인되지 않은 항목은 **미확인**이며, 미지원으로 판정하지 않는다. 모바일 동작 설명은 한컴의 오래된 Android 도움말에 근거한다. 현재 한컴독스 앱과 같은 UI라고 단정하지 않는다. 설치형 설명 일부는 공식 `hoffice130_assistant` 도움말을 함께 사용했다. 제품 업데이트·스킨·추가 기능에 따라 실제 메뉴 배치는 달라질 수 있다.

## 2. 설치형 한글의 UI

### 전체 배치

[공식 화면 구성 설명][desktop-screen]과 [실제 화면 이미지][desktop-image]를 확인했다. 다음은 영역 관계를 이해하기 위한 재구성 도식이며 픽셀 단위 설계도가 아니다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 제목·문서명                         로그인·설정·도움말·창 제어 │
├─────────────────────────────────────────────────────────────┤
│ 파일  편집  보기  입력  서식  쪽  보안  검토  도구             │
├─────────────────────────────────────────────────────────────┤
│ 선택한 메뉴 / 개체에 맞는 그룹별 도구                         │
├─────────────────────────────────────────────────────────────┤
│ 스타일 · 글꼴 · 크기 · 글자 모양 · 문단 정렬 등 서식 도구     │
├─────────────────────────────────────────────┬───────────────┤
│ 눈금자                                      │ 작업 창       │
│      ┌──────────────────────────┐           │ 스타일 등     │
│      │ 흰 종이 위 본문·표·그림  │           │ 상세 도구     │
│      │ 커서·선택·편집 결과      │           │               │
│      └──────────────────────────┘           │               │
├─────────────────────────────────────────────┴───────────────┤
│ 문서 탭                                                     │
│ 상태 정보 · 쪽 이동 · 보기 설정 · 확대/축소                   │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 공식 UI의 역할 | 웹 에디터에 적용할 점 — 제안 |
| --- | --- | --- |
| 메뉴 | 기본 9개 메뉴로 기능 분류 | 기능이 늘어나면 파일·편집·삽입·서식·쪽으로 묶기 |
| 기본 도구 상자 | 메뉴 및 선택한 개체에 따라 바뀜 | 본문·표·사진 선택에 맞춰 도구 교체 |
| 서식 도구 상자 | 자주 쓰는 글꼴·크기·정렬 등을 빠르게 조절 | 기본 글자 서식은 찾기 쉬운 위치에 두기 |
| 편집 창·눈금자 | 종이 배치와 개체 위치·크기 확인 | 종이 중심 화면 유지, 눈금자는 선택적으로 제공 |
| 작업 창 | 스타일 등 보조 편집 기능 제공 | 사진·표의 상세 속성 패널로 활용 |
| 문서 탭·상황 선 | 열린 문서와 편집 상태·이동 정보 표시 | 파일명, 수정 여부, 현재 쪽, 저장 상태 명시 |

영역 구분의 근거: [화면 구성][desktop-screen]. 확대 도구 등 보기 기능의 근거: [보기 탭][desktop-view]. 공식 화면에는 기본 메뉴 외의 추가 항목도 보여서, 기본 9개 메뉴가 모든 설치 환경의 전체 탭 수를 뜻하지는 않는다.

### 메뉴·개체 선택에 따른 변화

메뉴 이름을 누르면 해당 도구 상자로 바뀌며, 메뉴의 펼침 버튼은 목록을 연다. 파일 메뉴는 펼침 목록으로 동작한다. 오른쪽 클릭은 현재 상태에서 쓸 수 있는 명령과 단축키를 보여 준다. [메뉴 및 빠른 메뉴][desktop-menu]

그림에는 **그림 탭**, 표 관련 도움말에는 **표 디자인·표 레이아웃** 도구가 나타난다. 개체의 상세 값은 **개체 속성 / 표·셀 속성** 대화 상자로 조절한다. 모든 속성이 우측 작업 창에만 모여 있는 UI는 아니다. [그림 탭][desktop-picture], [표 레이아웃 탭][desktop-table-layout], [표/셀 속성][desktop-table-properties]

### 텍스트 편집 흐름

본문에 커서를 놓고 입력하며, 글자 범위를 선택해 서식을 바꾼다. 글자·문단 모양과 스타일은 별도 도구로 제공된다. **Enter는 문단을 나누고 Shift+Enter는 문단 안에서 줄을 나눈다.** [문단 모양][desktop-paragraph]

범위 선택은 마우스나 키보드로 할 수 있다. Shift+방향키는 원하는 만큼 선택하고, Shift+Home/End는 커서부터 줄의 처음/끝까지 선택한다. F3을 반복해서 누르면 낱말, 문단, 문서 전체로 선택 범위를 넓힐 수 있다. 선택한 내용은 입력으로 교체할 수 있고, 복사·잘라내기·삭제·서식 변경도 할 수 있다. [블록 설정][desktop-block], [단축키 일람][desktop-shortcuts]

커서는 방향키로 글자와 줄 사이를 이동한다. Ctrl+방향키는 낱말이나 문단 단위로 이동한다. Home/End는 현재 줄, Alt+Home/End는 문단, Ctrl+Home/End는 문서 처음/끝으로 이동한다. 찾기·바꾸기는 현재 커서 위치를 기준으로 문서 내용을 찾거나 바꾼다. [단축키 일람][desktop-shortcuts], [찾기][desktop-find]

### 표 편집 흐름

1. 입력에서 표를 선택하고 격자나 숫자로 행·열 수를 정한다.
2. 표가 생기면 첫 셀에서 내용을 입력한다.
3. 셀 또는 셀 범위를 기준으로 행·열 변경, 병합·분할, 정렬을 실행한다.
4. 상세 속성에서 쪽 경계 처리와 여백 등을 조절한다.

근거: [표 만들기][desktop-table-create], [표 레이아웃][desktop-table-layout], [표/셀 속성][desktop-table-properties]. 여러 쪽의 표와 병합 셀을 편집할 때 구조와 배치를 함께 고려해야 한다는 개발상의 판단을 뒷받침한다.

### 그림 편집 흐름과 배치 규칙

그림을 선택하면 전용 도구로 바뀐다. 교체할 때 기존 틀 크기를 유지할 수 있으며, 자세한 위치·크기는 속성 대화 상자에서 지정한다. [그림 탭][desktop-picture], [개체 속성][desktop-object]

**글자처럼 취급**은 글의 이동을 따라가는 배치다. 떠 있는 개체는 어울림·자리 차지·글 앞·글 뒤를 정하고 위치의 기준과 거리를 설정한다. 따라서 화면의 x/y만 바꾸는 것과 문서의 배치 규칙을 바꾸는 것은 다른 작업이다. 공식 도움말에서는 글자처럼 취급한 개체의 회전·기울이기에 제한도 명시한다. [개체 속성: 기본][desktop-object-basic]

현재 프로젝트의 그림 기능을 넓힐 때는 **그림 파일 추출·용량 줄이기·원본 복원·캡션·개체 보호**를 검토할 수 있다. 특히 현재 자르기는 새 비트맵을 만드는 방식이므로, 실행 취소 이력과 별개로 원본을 보존하려면 저장 모델 검토가 필요하다. 이는 프로젝트에 대한 제안이며 한컴 내부 구현을 조사한 결과는 아니다. [그림 관련 공식 기능][desktop-picture], [현재 사진 편집](../../README.md#사진-편집)

| 이용 구분 | 무료 웹·모바일 보기/편집 제공; 설치형 편집은 구독 조건 구분 | [시작하기][docs-start], [문서 편집 안내][docs-edit] |
| AI 관련 | 최근 웹한글 릴리스에 웹어시스턴트 개선 항목 존재 | [릴리스 노트][docs-release] — 세부 기능·이용 조건은 별도 확인 필요 |

클라우드 버전 관리의 20개는 키 입력 단위의 실행 취소 횟수와 다른 개념이다. 현재 프로젝트의 100단계 실행 취소와 직접 비교하지 않는다.

### 웹 UI에서 확인한 것

공식 안내에서는 **홈/파일 목록 → 문서 만들기 또는 파일 선택 → 더보기의 웹으로 열기 → 웹 편집 → 저장** 흐름을 설명한다. 파일의 공유·관리 명령도 더보기 메뉴에서 접근한다. 이것은 문서 관리 화면의 흐름이며, 편집기 내부의 모든 도구 배치를 설명하는 자료는 아니다. [문서 생성·편집 안내와 화면 예시][docs-edit], [공유·관리 안내][docs-use]

비로그인 브라우저에서 `https://hwp.hancom.com/`에 접속했을 때 조사 환경에서는 한컴독스 소개 페이지로 이동했다. 편집기 내부를 직접 조작하지 못했으므로 설치형과 동일한 리본, 사진 속성, 표 병합 도구를 현행 웹 UI에서 확인했다고 기록하지 않았다. [공식 서비스 진입 주소][docs-start]

### 공식 안내의 불일치

- [협업 가이드가 포함된 안내][docs-use]는 웹한글 편집 문서 **50 MB**, 협업 가이드 인원 **영문 10명 / 국문 5명**을 표시한다. 가이드 인원을 보장된 동시 편집 상한으로 단정하지 않는다.
- [다른 공식 사용 안내][docs-use-alternate]는 웹한글 **100 MB**를 표시한다.

두 페이지의 적용 버전·개정 순서를 확정할 수 없어 실제 한도를 단정하지 않는다. 서비스에서 재확인이 필요하다. 클라우드 저장 공간과 개별 문서의 편집 가능 크기도 구분해야 한다.

### 아직 확인이 필요한 웹 편집 기능

글자·문단 서식의 세부 범위, 표 생성·행/열 변경·병합/분할, 그림 자르기·회전·배치, 머리말·각주·수식 편집, 변경 추적, 인쇄/PDF 출력, 오프라인 동작은 **이번 웹한글 조사에서 세부 확인하지 않았다**. 설치형 기능 목록을 웹 제품의 지원표로 재사용하지 않는다.

## 5. 모바일 앱과 휴대폰 브라우저

한컴독스 공식 안내는 Android/iOS 앱에서 모든 요금제의 보기·편집을 제공한다고 설명한다. Windows의 모든 개체·서식 도구가 모바일에 있다고 판단할 근거는 아니다. [모바일 지원 범위][docs-start]

### Android용 한컴오피스 모바일 한글 도움말에서 확인한 UI

공식 모바일 도움말은 상단 **메뉴 표시줄**에 닫기, 되돌리기, 다시 실행, 입력, 편집, 파일을 둔다. 입력과 편집은 메뉴 아이콘이다. 아이콘을 누르면 화면 아래에 개체별 작업 창이나 선택 상태별 편집 창이 열린다. 도움말은 이 창을 작업 창이라고 부른다. [모바일 한글 도움말][mobile-help]

```text
┌─────────────────────────────┐
│ 닫기  되돌리기  다시 실행   │
│ 입력  편집  파일             │  상단 메뉴 표시줄
├─────────────────────────────┤
│                             │
│      종이 문서 화면          │  직접 터치해 커서·선택·개체 지정
│      글자 / 표 / 그림        │
│                             │
├─────────────────────────────┤
│ 현재 메뉴의 작업 창         │  입력: 개체 탭
│ 글자 모양 / 문단 모양 등     │  편집: 선택별 도구 탭
└─────────────────────────────┘
```

도움말은 **빠른 메뉴**를 별도 UI로 설명한다. 본문 커서를 누르거나 글자를 블록으로 선택하거나 도형·그림·차트·표를 선택한 뒤 누르면, 현재 대상에 맞는 팝업 명령이 나온다. 즉, 한 화면에서 같은 도구만 고정해 쓰지 않는다. 현재 선택에 따라 빠른 메뉴와 작업 창을 바꾼다. [모바일 한글 도움말][mobile-help]

모바일 도움말은 구형 앱의 문서를 포함한다. 예를 들어 인쇄 설명은 Google 클라우드 프린트를 요구한다. 이 서비스는 현재 Android UI의 근거로 쓰지 않았다. 아래의 터치 편집 원리는 공식 문서에 명시된 절차로 한정한다. 최신 한컴독스 모바일 앱의 전체 화면과 같다는 뜻은 아니다.

### Android에서 글자를 직접 고치는 방식

| 사용자가 하는 동작 | 공식 도움말에 적힌 반응 |
| --- | --- |
| 글자를 두 번 누름 | 해당 글자를 선택한다. |
| 선택한 글자를 다시 누름 | 선택 상태의 빠른 메뉴를 연다. |
| 빠른 메뉴에서 복사·오려 두기 | 선택한 글자를 복사하거나 잘라낸다. |
| 붙일 위치를 누른 뒤 붙이기 | 현재 커서 위치에 글자를 넣는다. |
| 글자 범위를 선택한 뒤 편집 메뉴를 누름 | 글자 모양 작업 창에서 굵게·기울임·취소선, 글꼴·색·크기를 바꾼다. |
| 문단을 선택한 뒤 문단 모양을 엶 | 정렬, 글머리표, 문단 번호를 바꾼다. |
| 커서 위치를 누른 뒤 입력 메뉴를 엶 | 표·도형·그림·차트·수식 등 삽입 창을 연다. |

공식 도움말은 단어를 두 번 눌러 선택하는 절차를 명시한다. 손가락을 길게 눌러 선택 핸들을 표시하는 방식, 단어 경계 계산, 키보드가 열린 상태에서의 포커스 규칙은 해당 문서에 설명하지 않는다. 이를 한컴의 확인된 동작으로 적지 않는다. [모바일 글자 편집][mobile-help]

글자 서식은 두 흐름을 제공한다. 사용자는 먼저 범위를 선택한 뒤 편집 작업 창에서 속성을 바꿀 수 있다. 스타일은 현재 커서나 문단에 적용할 수 있다. 서식은 페이지 그림을 덮어 쓰는 효과가 아니라 문서의 글자/문단 속성을 바꾼다. 후자의 설명은 공식 절차에서 얻은 편집 모델의 해석이다. [모바일 글자 편집][mobile-help]

### Android의 표·개체 편집 방식

| 대상 | 선택·편집 흐름 |
| --- | --- |
| 표 삽입 | 입력 메뉴 → 아래 작업 창의 표 탭 → 격자에서 행·열을 손가락으로 끌어 지정 |
| 표 선택 | 표 밖에서는 표를 누른다. 셀 안에서는 커서를 누른 뒤 빠른 메뉴에서 표 선택을 누른다. |
| 셀 선택 | 셀 안의 커서를 누른 뒤 빠른 메뉴에서 셀 선택을 누른다. 표가 선택된 상태에서는 원하는 셀을 누른다. |
| 셀 범위 선택 | 먼저 한 셀을 블록으로 만들고, 그 셀을 누른 채 원하는 방향으로 끈다. |
| 표/셀 크기 변경 | 선택 핸들이나 셀 테두리를 누른 뒤 끈다. |
| 행·열 추가 | 셀 범위를 선택하고 편집 작업 창의 편집 탭에서 추가 명령을 고른다. |
| 셀 합치기/나누기 | 합칠 셀을 블록으로 선택한다. 나누기는 셀을 고르고 줄·칸 수를 입력한다. |
| 그림·도형·차트 등 삽입 | 입력 메뉴를 누른 뒤 화면 아래에 열린 개체 탭에서 종류를 선택한다. |
| 개체 꾸미기 | 개체를 선택하고 그리기 속성 탭에서 채우기·선·음영·그림자 등을 고른다. |
| 여러 개체 선택 | 개체를 선택하고 다시 눌러 빠른 메뉴를 연다. 다중 선택을 고른 뒤 대상들을 차례로 누른다. |
| 개체 회전 | 개체를 선택하고 도형 메뉴의 정렬/크기 탭에서 회전을 고른다. 원형 핸들을 끌거나 90도 회전 명령을 쓴다. |
| 그림 자르기 | 그림을 선택하고 그림 메뉴의 그리기 속성에서 자르기를 연다. 8개 경계 핸들을 끌고 문서 화면을 눌러 적용한다. |
| 개체 배치 | 정렬/크기 탭에서 글자처럼 취급, 어울림, 자리 차지, 글 앞으로/뒤로 중 배치를 고른다. |
| 차트 데이터 | 차트를 선택하고 빠른 메뉴나 편집 탭에서 데이터 편집을 연다. 데이터 표에서 행·열을 추가·삭제하고 적용한다. |
| 자유형 도형 | 입력 메뉴의 기타 탭에서 자유형 직접 그리기를 연다. 화면에 그리고 도형 인식으로 모양을 보정할 수 있다. |

공식 도움말에는 한 손가락으로 첫 개체를 누른 상태에서 다른 손가락으로 다음 개체를 선택하는 방법도 있다. 개체 편집은 우선 대상 선택이 필요하다. 선택된 다음에 크기·회전·스타일·정렬 도구를 연다. [모바일 표·개체 편집][mobile-help]

모바일 도움말은 회전·자르기·배치·차트 데이터 편집을 설명한다. 모든 개체의 직접 크기 조절과 세부 속성은 설명하지 않는다. 위 표 밖의 동작은 공식 미확인으로 남긴다. 설치형 도움말에는 그림 탭과 개체 속성이 따로 있다. 설치형의 도구 이름과 구성이 모바일에도 같다고 가정하지 않는다. [설치형 그림 도구][desktop-picture], [설치형 개체 속성][desktop-object]

### 모바일과 설치형의 차이

| 작업 | Windows 설치형 한글 | 모바일 도움말에서 확인한 방식 |
| --- | --- | --- |
| 입력 포커스 | 편집 종이에서 커서를 놓고 키보드로 입력 | 본문을 터치해 커서를 지정하고 모바일 키보드로 입력하는 편집기. 도움말은 IME 세부 동작은 설명하지 않음 |
| 글자 범위 | 마우스 드래그, Shift+방향키, F3 블록 | 글자를 두 번 눌러 선택. 선택·빠른 메뉴는 터치 중심 |
| 도구 찾기 | 메뉴 탭과 서식 도구 상자 | 상단 아이콘에서 아래 작업 창을 열고 현재 선택용 도구를 고름 |
| 표 선택 | 표/셀 선택 모드와 키보드 명령 | 표/셀을 누른 뒤 빠른 메뉴로 선택 상태를 바꿈 |
| 개체 선택 | 개체 테두리·핸들, 마우스 또는 단축키 | 개체를 누르고 빠른 메뉴·아래 작업 창으로 편집 |
| 개체 여러 개 선택 | Shift+클릭·선택 사각형 | 빠른 메뉴의 다중 선택 또는 두 손가락 선택 |

설치형의 글자 선택·개체 선택은 [단축키 도움말][desktop-shortcuts], [개체 선택 도움말][desktop-object-select]에 근거한다. 모바일 열은 [공식 모바일 도움말][mobile-help]에 적힌 동작만 기록했다.

## 6. 렌더링 페이지를 편집기로 바꿀 때 필요한 동작

이 절은 한컴 도움말에 적힌 동작을 Android 렌더링 편집기에 적용한 **제품 설계 제안**이다. 한컴의 내부 구현을 설명하지 않는다.

### 탭한 자리에서 문자를 편집하기

1. 사용자가 렌더링된 글자 위를 누른다.
2. 엔진은 화면 좌표를 원본 문서의 문단·문자 위치로 바꾼다.
3. 편집기는 그 위치에 커서를 그리고 키보드를 연다.
4. 사용자는 글자를 입력하거나 삭제한다. IME가 조합 중인 한글도 커서와 함께 표시한다.
5. 엔진은 본문을 다시 배치하고 페이지를 다시 그린다. 커서는 새 글자 위치를 유지한다.
6. 범위 선택이 있으면 선택 핸들로 범위를 늘리고, 서식 도구는 그 범위에 적용한다.

이 방식은 **텍스트 구간 전체를 별도 입력 상자로 바꾸는 것과 다르다**. 구간 입력 상자는 실제 문서의 커서 위치, 글자 폭, 한글 조합, 줄바꿈, 페이지 나눔과 계속 동기화되지 않는다. 이 차이는 한컴의 공식 동작 설명과 직접 입력 UI를 바탕으로 한 설계 판단이다.

### 선택 상태에 따라 도구를 바꾸기

| 선택 상태 | 기본 편집 동작 | 화면 도구 제안 |
| --- | --- | --- |
| 본문 커서 | 삽입·삭제·문단 나누기 | 글자/문단 서식, 입력, 실행 취소 |
| 글자 범위 | 바꾸기·복사·삭제·서식 | 복사/잘라내기 팝업, 글자 모양 |
| 표 셀 커서 | 셀 안 본문 입력 | 셀 이동·표 선택·셀 선택 빠른 메뉴 |
| 셀 범위 | 여러 셀 대상으로 구조 변경 | 행/열 추가·삭제, 병합·분할, 셀 속성 |
| 그림/도형/차트 | 대상 이동·크기 변경·속성 수정 | 선택 핸들, 대상 전용 도구와 속성 패널 |

한컴 모바일 도움말은 빠른 메뉴와 하단 작업 창으로 선택 상태별 명령을 분리한다. 이것이 단순히 상단에 고정 버튼을 늘리는 것보다 가까운 참고 모델이다. 다만 실제 Android 화면에서는 손가락·화면 크기에 맞게 배치해야 한다.

### 입력과 문서 구조

Windows 한글에서는 **Enter가 새 문단**을 만들고 **Shift+Enter가 같은 문단 안에서 강제 줄바꿈**을 만든다. 표 안의 Enter와 Ctrl+Enter도 표 문맥에서 다른 명령이 될 수 있다. 문서의 문단·줄·표 셀 구분을 화면의 줄바꿈 문자 하나로 축약하면 안 된다. [문단 모양 도움말][desktop-paragraph], [쪽 나누기 도움말][desktop-page-break]

렌더링 엔진은 페이지 표시를 위해 원본 문서 위치와 글자 박스를 연결해야 한다. 터치 위치를 단순히 가장 가까운 줄이나 텍스트 구간의 시작점에 붙이면 가운데 문자를 눌러도 커서가 구간 앞에 놓일 수 있다. 따라서 문자별 또는 글리프별 경계, 줄/문단 경계, 겹치는 개체를 고려한 hit-test가 필요하다. 이는 구현 요건에 대한 판단이다.

## 7. 조사 한계와 구현 시사점

이 문서는 설치형 Windows 도움말과 한컴의 공개 모바일 도움말을 조사했다. 모바일 도움말은 오래된 Android 앱 안내다. 최신 한컴독스 앱과 UI가 같다고 보장하지 않는다. 한컴의 실제 바이너리 UI나 내부 커서 엔진은 조사하지 않았다.

Android HWP 편집기를 설계할 때 먼저 필요한 기준은 다음과 같다.

1. 터치한 문자의 원본 위치에 커서를 놓고 바로 입력한다.
2. 한글 IME 조합 중인 글자와 선택 범위를 문서 모델에 연결한다.
3. 본문·글자 범위·표 셀·표 범위·그림 등의 선택 상태를 구분한다.
4. 선택 상태에 따라 빠른 메뉴와 도구 창을 바꾼다.
5. 입력 뒤 문단·표·개체를 다시 배치하고 커서 위치를 유지한다.
6. HWP/HWPX 저장 후 다시 열어 편집 결과와 개체 구조를 확인한다.

이 기준은 한컴의 내부 구현 사양이 아니다. 공식 문서가 설명하는 사용자 동작을 Android 렌더링 편집기로 옮긴 설계 요구다.

## 8. 검증 체크리스트

- Android 한글과 한컴독스 모바일 앱을 구분하고 조사 날짜와 버전을 기록한다.
- 본문 중간·문단 끝·표 셀 안에서 터치해 커서가 맞는 문자 위치에 놓이는지 확인한다.
- 한글 조합, 연속 입력, 삭제, Enter, 줄바꿈, 실행 취소를 확인한다.
- 글자 선택 핸들로 범위를 늘리고 복사·잘라내기·붙여넣기·서식 변경을 확인한다.
- 표 선택과 셀 선택이 다르게 동작하는지 확인한다.
- 셀 범위 선택, 행·열 추가·삭제, 셀 합치기·나누기 후 구조를 확인한다.
- 그림·도형·차트를 본문과 표 안에서 선택하고, 이동·크기·속성 편집을 확인한다.
- 확대·축소, 세로 스크롤, 화면 회전, 키보드 표시/숨김 중 커서와 선택 위치를 확인한다.
- 저장한 HWP/HWPX를 다시 열고 본문·쪽 배치·표·그림이 보존되는지 비교한다.
- 실패한 편집은 원복하고 문서 손상 없이 다시 열리는지 확인한다.
