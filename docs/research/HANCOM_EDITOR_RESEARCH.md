# 한컴 에디터 기능·UI 조사

- 조사 기준일: **2026-10-05**
- 목적: 이 저장소의 HWP 웹 에디터를 확장할 때 참고할 실제 제품의 기능, 화면 구성, 편집 흐름 정리
- 비교 기준: 현재 프로젝트 `7e00f00`의 [README](../../README.md)
- 자료: 한컴 공식 도움말·고객지원·릴리스 노트, 공식 화면 이미지, 비로그인 웹 접속 확인

## 1. 조사 범위와 확인 수준

한컴의 편집기는 플랫폼별로 구분해야 한다. Windows 한글의 기능을 웹한글이나 모바일 앱의 기능으로 그대로 간주하지 않았다.

| 제품 | 이번 조사에서 확인한 것 | 확인하지 못한 것 |
| --- | --- | --- |
| Windows 설치형 **한글 2024** | `hoffice130` 계열 공식 도움말의 기능·메뉴, 공식 편집 화면 이미지 | 프로그램을 직접 실행한 편집·저장 및 문서 호환성 시험 |
| **한컴독스 웹한글** | HWP/HWPX 편집, 문서 관리·공유·저장 안내, 웹한글 릴리스 정보 | 로그인 후 편집 화면의 모든 버튼, 설치형 대비 세부 기능 차이 |
| **한컴독스 모바일 앱** | Android/iOS에서 보기·편집 제공, 앱 릴리스 정보 | 현행 앱의 전체 도구 구성과 기기별 터치·키보드 동작 |
| **휴대폰 브라우저의 웹한글** | 공식 지원 브라우저 목록 | 모바일 앱과의 기능 동등성, 좁은 화면에서의 편집 UI |

웹한글의 조사 시점 최신 공개 항목은 **v2.5.6.2 / 2026-09-01**, 모바일은 **v2.0.12 / 2026-07-14**다. 이는 공개 릴리스 노트 기준이며, 실제 접속 인스턴스의 빌드를 조회한 결과는 아니다. 같은 페이지의 웹서비스·웹오피스 버전 번호와 혼용하지 않는다. [공식 릴리스 노트][docs-release]

아래에서 **공식 확인**은 문서·이미지에서 확인했다는 뜻이다. 세부 지원 여부가 확인되지 않은 항목은 **미확인**이며, 미지원으로 판정하지 않는다. 설치형 설명 일부는 공식 `hoffice130_assistant` 도움말을 함께 사용했다. 제품 업데이트·스킨·추가 기능에 따라 실제 메뉴 배치는 달라질 수 있다.

## 2. 설치형 한글의 UI

### 전체 배치

[공식 화면 구성 설명][desktop-screen]과 [실제 화면 이미지][desktop-image]를 확인했다. 다음은 영역 관계를 이해하기 위한 재구성 도식이며 픽셀 단위 설계도가 아니다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 제목·문서명                         로그인·설정·도움말·창 제어 │
├─────────────────────────────────────────────────────────────┤
│ 파일  편집  보기  입력  서식  쪽  보안  검토  도구             │
├─────────────────────────────────────────────────────────────┤
│ 선택한 메뉴 / 개체에 맞는 그룹별 도구                         │
├─────────────────────────────────────────────────────────────┤
│ 스타일 · 글꼴 · 크기 · 글자 모양 · 문단 정렬 등 서식 도구     │
├─────────────────────────────────────────────┬───────────────┤
│ 눈금자                                      │ 작업 창       │
│      ┌──────────────────────────┐           │ 스타일 등     │
│      │ 흰 종이 위 본문·표·그림  │           │ 상세 도구     │
│      │ 커서·선택·편집 결과      │           │               │
│      └──────────────────────────┘           │               │
├─────────────────────────────────────────────┴───────────────┤
│ 문서 탭                                                     │
│ 상태 정보 · 쪽 이동 · 보기 설정 · 확대/축소                   │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 공식 UI의 역할 | 웹 에디터에 적용할 점 — 제안 |
| --- | --- | --- |
| 메뉴 | 기본 9개 메뉴로 기능 분류 | 기능이 늘어나면 파일·편집·삽입·서식·쪽으로 묶기 |
| 기본 도구 상자 | 메뉴 및 선택한 개체에 따라 바뀜 | 본문·표·사진 선택에 맞춰 도구 교체 |
| 서식 도구 상자 | 자주 쓰는 글꼴·크기·정렬 등을 빠르게 조절 | 기본 글자 서식은 찾기 쉬운 위치에 두기 |
| 편집 창·눈금자 | 종이 배치와 개체 위치·크기 확인 | 종이 중심 화면 유지, 눈금자는 선택적으로 제공 |
| 작업 창 | 스타일 등 보조 편집 기능 제공 | 사진·표의 상세 속성 패널로 활용 |
| 문서 탭·상황 선 | 열린 문서와 편집 상태·이동 정보 표시 | 파일명, 수정 여부, 현재 쪽, 저장 상태 명시 |

영역 구분의 근거: [화면 구성][desktop-screen]. 확대 도구 등 보기 기능의 근거: [보기 탭][desktop-view]. 공식 화면에는 기본 메뉴 외의 추가 항목도 보여서, 기본 9개 메뉴가 모든 설치 환경의 전체 탭 수를 뜻하지는 않는다.

### 메뉴·개체 선택에 따른 변화

메뉴 이름을 누르면 해당 도구 상자로 바뀌며, 메뉴의 펼침 버튼은 목록을 연다. 파일 메뉴는 펼침 목록으로 동작한다. 오른쪽 클릭은 현재 상태에서 쓸 수 있는 명령과 단축키를 보여 준다. [메뉴 및 빠른 메뉴][desktop-menu]

그림에는 **그림 탭**, 표 관련 도움말에는 **표 디자인·표 레이아웃** 도구가 나타난다. 개체의 상세 값은 **개체 속성 / 표·셀 속성** 대화 상자로 조절한다. 모든 속성이 우측 작업 창에만 모여 있는 UI는 아니다. [그림 탭][desktop-picture], [표 레이아웃 탭][desktop-table-layout], [표/셀 속성][desktop-table-properties]

### 텍스트 편집 흐름

본문에 커서를 놓고 입력하며, 글자 범위를 선택해 서식을 바꾼다. 글자·문단 모양과 스타일은 별도 도구로 제공된다. **Enter는 문단을 나누고 Shift+Enter는 문단 안에서 줄을 나눈다.** 현재 프로젝트의 Enter 동작과 구분해야 한다. [서식 탭][desktop-format], [단축키 일람][desktop-shortcuts]

### 표 편집 흐름

1. 입력에서 표를 선택하고 격자나 숫자로 행·열 수를 정한다.
2. 표가 생기면 첫 셀에서 내용을 입력한다.
3. 셀 또는 셀 범위를 기준으로 행·열 변경, 병합·분할, 정렬을 실행한다.
4. 상세 속성에서 쪽 경계 처리와 여백 등을 조절한다.

근거: [표 만들기][desktop-table-create], [표 레이아웃][desktop-table-layout], [표/셀 속성][desktop-table-properties]. 여러 쪽의 표와 병합 셀을 편집할 때 구조와 배치를 함께 고려해야 한다는 개발상의 판단을 뒷받침한다.

### 그림 편집 흐름과 배치 규칙

그림을 선택하면 전용 도구로 바뀐다. 교체할 때 기존 틀 크기를 유지할 수 있으며, 자세한 위치·크기는 속성 대화 상자에서 지정한다. [그림 탭][desktop-picture], [개체 속성][desktop-object]

**글자처럼 취급**은 글의 이동을 따라가는 배치다. 떠 있는 개체는 어울림·자리 차지·글 앞·글 뒤를 정하고 위치의 기준과 거리를 설정한다. 따라서 화면의 x/y만 바꾸는 것과 문서의 배치 규칙을 바꾸는 것은 다른 작업이다. 공식 도움말에서는 글자처럼 취급한 개체의 회전·기울이기에 제한도 명시한다. [개체 속성: 기본][desktop-object-basic]

현재 프로젝트의 그림 기능을 넓힐 때는 **그림 파일 추출·용량 줄이기·원본 복원·캡션·개체 보호**를 검토할 수 있다. 특히 현재 자르기는 새 비트맵을 만드는 방식이므로, 실행 취소 이력과 별개로 원본을 보존하려면 저장 모델 검토가 필요하다. 이는 프로젝트에 대한 제안이며 한컴 내부 구현을 조사한 결과는 아니다. [그림 관련 공식 기능][desktop-picture], [현재 사진 편집](../../README.md#사진-편집)

### 웹 UI에서 확인한 것

공식 안내에서는 **홈/파일 목록 → 문서 만들기 또는 파일 선택 → 더보기의 웹으로 열기 → 웹 편집 → 저장** 흐름을 설명한다. 파일의 공유·관리 명령도 더보기 메뉴에서 접근한다. 이것은 문서 관리 화면의 흐름이며, 편집기 내부의 모든 도구 배치를 설명하는 자료는 아니다. [문서 생성·편집 안내와 화면 예시][docs-edit], [공유·관리 안내][docs-use]

비로그인 브라우저에서 `https://hwp.hancom.com/`에 접속했을 때 조사 환경에서는 한컴독스 소개 페이지로 이동했다. 편집기 내부를 직접 조작하지 못했으므로 설치형과 동일한 리본, 사진 속성, 표 병합 도구를 현행 웹 UI에서 확인했다고 기록하지 않았다. [공식 서비스 진입 주소][docs-start]

### 공식 안내의 불일치

- [협업 가이드가 포함된 안내][docs-use]는 웹한글 편집 문서 **50 MB**, 협업 가이드 인원 **영문 10명 / 국문 5명**을 표시한다. 가이드 인원을 보장된 동시 편집 상한으로 단정하지 않는다.
- [다른 공식 사용 안내][docs-use-alternate]는 웹한글 **100 MB**를 표시한다.

두 페이지의 적용 버전·개정 순서를 확정할 수 없어 실제 한도를 단정하지 않는다. 서비스에서 재확인이 필요하다. 클라우드 저장 공간과 개별 문서의 편집 가능 크기도 구분해야 한다.

### 아직 확인이 필요한 웹 편집 기능

글자·문단 서식의 세부 범위, 표 생성·행/열 변경·병합/분할, 그림 자르기·회전·배치, 머리말·각주·수식 편집, 변경 추적, 인쇄/PDF 출력, 오프라인 동작은 **이번 웹한글 조사에서 세부 확인하지 않았다**. 설치형 기능 목록을 웹 제품의 지원표로 재사용하지 않는다.

## 5. 모바일 앱과 휴대폰 브라우저

한컴독스 공식 안내는 Android/iOS 앱에서 모든 요금제의 보기·편집 제공을 명시한다. 이것만으로 Windows의 모든 개체·서식 도구나 휴대폰 브라우저에서 같은 UI를 제공한다고 판단할 수는 없다. [모바일 지원 범위][docs-start]

검색으로 발견되는 [iPad 한글 사용자 안내서][legacy-ipad]에는 **2013년 저작권 표기와 iOS 5.0 기준**이 있어, 현행 앱의 화면·지원 기능 근거에서 제외했다. 검색 결과의 최근 수집 날짜를 제품 출시·개정 날짜로 취급하지 않는다.

현재 프로젝트는 모바일 사용 경험을 별도로 설계할 필요가 있다. 다음은 **우리 제품에 대한 제안**이다.

- 기본 도구는 열기·저장·실행 취소와 현재 선택에 필요한 항목을 우선한다.
- 사진은 첫 터치로 선택하고 다음 드래그로 이동하는 현재 동작을 유지한다.
- 크기·배치 같은 상세 설정은 하단 패널로 제공하고 키보드와 문서를 함께 볼 공간을 확보한다.
- 텍스트 커서, 셀 선택, 사진 선택을 시각적으로 구분한다.
- Android·iOS 실기기에서 한글 조합, 사진 선택·스크롤, 화면 회전, 키보드 표시/숨김을 검증한다.

## 6. 현재 프로젝트와의 차이

이 표의 프로젝트 상태는 조사 기준 커밋의 README에 근거한다. 개체가 화면에 보이거나 저장 시 보존되는 것과, 사용자가 그 개체를 편집할 수 있는 것은 구분했다. [현재 지원 범위](../../README.md)

| 기능 | 설치형 한글의 확인된 기능 | 현재 웹 에디터 |
| --- | --- | --- |
| 본문·표 셀 글자 | 본문·셀 편집과 문단/서식 도구 | 일반 본문·일반 셀의 글자 편집; 보호 범위 제한 |
| 문단 구조 | 문단 분리·문단 안 줄 나눔 | Enter는 같은 문단의 줄바꿈; 문단 생성·삭제·합치기 없음 |
| 범위 선택 | 글자 블록을 통한 편집·서식 | 같은 문단 안의 선택; 문단을 넘는 선택 없음 |
| 글자·문단 서식 | 글꼴·크기·색·정렬·스타일 등 | 표시·일부 서식 승계; 직접 변경 도구 없음 |
| 표 구조·속성 | 생성, 행·열 변경, 병합·분할, 정렬·여백 | 기존 셀 내용 수정; 행·열·병합 구조 유지 |
| 사진 | 기본 편집과 관리·효과·속성 | 추가·교체·삭제·크기·자르기·회전·위치/배치 제공, 편집 가능한 본문·셀로 제한 |
| 쪽·구역 | 용지·여백·다단·머리말·꼬리말 등 | 렌더링 지원; 전용 편집 도구 없음 |
| 수식·도형·차트 | 삽입 및 개체별 도구 | 렌더링 지원; 개체 내용 편집 도구 없음 |
| 검토 | 메모·변경 추적·문서 비교 | 관련 편집 UI 없음 |
| 파일·저장 | 새 문서·다른 이름 저장·출력 | 기존 HWP/HWPX 편집 후 새 파일 다운로드 |
| 복구·협업 | 한컴독스에서 저장·버전·공유 제공 | 메모리의 100단계 실행 취소; 새로고침 복구·협업 없음 |
| UI | 메뉴별·개체별 도구, 서식 도구, 속성 대화 상자 | 간단한 상단 도구, 종이 화면, 사진 패널, 하단 상태 |

설치형 열의 근거는 [주요 지원 기능](#3-설치형-한글의-주요-지원-기능)의 각 기능별 공식 출처를 따른다. 복구·협업 행은 설치형 단독 기능이 아니라 [한컴독스 서비스][docs-use]와의 비교다.

## 7. 구현 순서 제안

조사 결과와 현재 편집 범위에서 도출한 개발 제안이다. 일정이나 엔진 API의 지원을 확정한 계획은 아니다. 세부 구현 전 [기존 개발 계획](../../HWP_WEB_PLAN.md)과 엔진의 수정·저장 가능 범위를 대조해야 한다.

| 순서 | 작업 | 필요한 이유·완료 기준 |
| --- | --- | --- |
| 1 | 문단 추가·분리·합치기, 문단을 넘는 선택 | Enter로 새 문단 작성, Backspace로 합치기, 실행 취소·저장 후 재열기에서 문단 구조와 범위 밖 서식 보존 |
| 2 | 기본 글자·문단 서식 | 글꼴·크기·굵게·색·정렬·줄 간격부터; 선택 범위와 혼합 서식 상태를 도구에 반영 |
| 3 | 표 전용 도구와 구조 편집 | 표 생성 → 행·열 추가/삭제 → 병합·분할 → 셀 여백·테두리; 병합 구조·다음 쪽 배치·실행 취소 검증 |
| 4 | 메뉴·선택별 UI 정리 | 기본 서식은 상단, 표·사진 도구는 선택에 따라 표시, 상세 값은 패널; 모바일 키보드가 떠도 문서 조작 가능 |
| 5 | 그림 관리 보강 | 원본 보존/복원, 추출, 용량 조절을 먼저 검토; 자르기 이후 재편집 가능성과 문서 크기 관리 |
| 6 | 쪽 설정·저장 복구 | 용지·여백·쪽 나누기와 로컬 자동 복구; 다운로드 저장과 임시 복구 상태를 구분 |
| 이후 | 복잡한 개체·검토·협업 | 글상자·수식·각주·변경 추적 등은 개체별 저장 검증 필요; 클라우드 협업은 서버·계정·동시 편집 설계가 별도 필요 |

가장 먼저 개선할 것은 **문단 구조와 기본 서식**이다. 현재는 문서 안의 글자·사진을 수정할 수 있지만, 새 문단을 만들고 원하는 모양을 정하는 기본 작성 흐름이 제한되어 있다. UI 확대는 각 기능을 실제로 편집·저장할 수 있는 범위에 맞춰 진행하는 편이 적절하다.

## 8. 후속 조사 체크리스트

- 현행 웹한글에 로그인해 본문·표·사진 선택별 화면과 도구를 기록한다.
- 동일한 HWP/HWPX 샘플을 설치형·웹·모바일에서 열어 표시·편집·저장 결과를 따로 비교한다.
- 웹의 표 구조 편집, 그림 배치, 각주·수식·머리말, PDF/인쇄를 개별 확인한다.
- 모바일 앱 UI와 휴대폰 브라우저 UI를 각각 기록한다.
- 실제 문서 크기 한도와 보호 문서 처리, 저장 실패·복구 동작을 확인한다.
- 조사 갱신 시 제품·버전·날짜·근거를 남기고 아래 출처가 이동했는지 확인한다.
