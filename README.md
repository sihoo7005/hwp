# HWP 뷰어와 단어 바꾸기 · 실험판

웹사이트: **[https://sihoo7005.github.io/hwp/](https://sihoo7005.github.io/hwp/)**

HWP/HWPX 문서의 그림·수식·표와 쪽 배치를 보고, 단순 HWP 5.0 본문의 같은 길이 단어를 바꿔 내려받는 웹사이트입니다. 문서와 비밀번호는 브라우저 안의 Worker에서 처리하며 외부 서버로 업로드하지 않습니다. 문서 엔진도 사이트에 함께 배포하므로 다른 사이트의 편집기에 문서를 보내지 않습니다.

## 실행

Node.js 24와 Python이 필요합니다.

```sh
npm ci --ignore-scripts --no-bin-links
npm test
npm run build
npm run serve
```

**http://127.0.0.1:8765** 에 접속합니다. 파일 앱에서 HTML을 직접 열면 Worker/WASM이 실행되지 않을 수 있습니다.

## 사용

1. 최대 32 MB의 문서를 선택합니다. 암호가 있으면 문서 비밀번호를 입력합니다. 틀린 암호는 다시 입력할 수 있습니다.
2. **쪽 보기**에서 그림·수식·표를 확인합니다. 이전/다음 버튼이나 쪽 번호로 이동하고, 너비 맞춤 또는 50~150% 확대를 선택합니다.
3. **텍스트** 보기에서는 글을 선택·복사합니다. 기존 자체 뷰어의 문단·표 표시와 치환 강조는 **기본 서식** 보기에서 확인합니다. 해당 파서로 열 수 없는 문서는 기본 서식 선택이 비활성화됩니다.
4. 단순 HWP 5.0 본문에서는 같은 길이의 한글·영문·숫자 문자열을 치환합니다. 예: `서울 → 부산`. 선택한 원본 기준으로 해당 문자열을 모두 바꾸며, 내용 선택에서 원본과 결과를 비교할 수 있습니다.
5. **결과 HWP 다운로드**로 새 파일을 내려받아 한글에서 확인합니다. 원본은 덮어쓰지 않습니다.

## 보기 지원 범위

쪽 보기는 MIT 라이선스의 **[@rhwp/core 0.8.6](https://github.com/edwardkim/rhwp/tree/v0.8.6)**를 고정 버전으로 사용합니다. 자체 파서의 기본 서식 뷰어와 치환기는 별도로 유지합니다.

| 문서/기능 | 지원 범위 |
| --- | --- |
| HWP 5.0 | 일반·압축·비압축·배포용 문서 보기 |
| HWPX | ZIP/XML 문서 보기. OWPML은 HWPX의 문서 구조로 처리 |
| 구형 HWP 3 | 읽기 지원. 모든 구형 문서의 재현을 보장하지 않음 |
| HML/HWPML XML | 엔진에서 해석 가능한 구조 보기. 2.9/2.91 계열에 범위가 제한되며 미지원 요소 안내 표시 |
| 암호 문서 | HWP5 EncryptVersion 4, 압축 HWP3, ODF AES-256-CBC HWPX. 올바른 비밀번호 필요 |
| 표 | 병합·중첩·배경·테두리·쪽 분할 등 엔진의 표 렌더링 |
| 그림·수식·도형·차트 | 엔진의 SVG 렌더링. 개체 종류에 따라 지원 정도가 다름 |
| 쪽과 본문 서식 | 쪽 나눔·다단, 글머리표/번호, 머리말·꼬리말·바탕쪽·각주·미주 등 엔진의 배치 |
| DRM·일부 구형 암호·손상 파일 | 미지원. 오류 안내, 암호 입력 또는 기본 서식/텍스트 확인 제공 |

**모든 한글 형식과 개체를 100% 지원하는 상태는 아닙니다.** 설치되지 않은 글꼴은 대체되며, Worker의 글꼴 측정과 엔진의 배치 때문에 원본과 줄바꿈·쪽 수가 달라질 수 있습니다. HML의 미지원 요소는 화면에서 생략됩니다. HWP 2.x 등 미검증 구형 버전, 특수 OLE/그림/수식·필드의 모든 변종 및 DRM은 완전 지원으로 취급하지 않습니다. HWPX/HML/HWP3와 복잡한 HWP는 보기만 지원하며 편집·저장 지원과 구분합니다.

최대 32 MB·5,000쪽, 텍스트 20만 글자, 한 쪽 SVG 16 MB·가로세로 16,384px까지 표시합니다. 선택한 쪽만 렌더링하고 문서별 최근 한 쪽을 보관합니다. 처리에 45초 이상 걸리면 Worker를 종료하고 안내합니다. 엔진 첫 로드에는 약 10 MB의 WASM 다운로드가 필요합니다.

문서 SVG는 HTML에 직접 삽입하지 않고 이미지로 표시하며, 텍스트도 HTML로 해석하지 않습니다. 문서 스크립트는 실행하지 않습니다. 비밀번호 입력란은 제출 직후 비우며 저장하지 않습니다.

## 치환·저장 제한

기존처럼 **8 MB 이하의 단순 HWP 5.0 본문만** 수정합니다. 표·그림·수식·필드 등 복잡한 구조, 암호·배포용·DRM·서명·문서 이력·변경추적 문서는 치환하지 않습니다. 보기 엔진의 내보내기 API를 연결해 편집 제한을 우회하지 않습니다.

찾기는 정규식이 아닌 대소문자를 구분하는 문자열 검색입니다. 단어 일부도 일치합니다. 다른 글자 수, 같은 단어, 공백·기호·이모지, 제어 문자 경계를 넘는 문자열은 거절합니다. 원본 레코드와 다른 스트림을 보존하며 `PrvText`를 갱신하고 이전 `PrvImage`는 제거합니다. 다운로드 전에 자체 파서로 본문·스트림을 재검사합니다. 자체 검사의 성공이 한글 프로그램의 호환성을 보장하지 않으므로 실제 한글에서 열기·편집·재저장을 확인해야 합니다.

## 검증

`npm test`는 기존 16개 검사와 확장 엔진 검사 1개를 실행합니다. 압축·레코드·스트림 보존, 미지원 편집 거절, 본문 서식, 병합·중첩 표, 그림·분수 수식, HWPX/HML 열기와 암호 문서의 올바른/틀린 암호를 확인합니다. 자동 검사의 내보내기 호출은 테스트용이며 사이트에 해당 저장 기능을 노출하지 않습니다.

브라우저 검사는 별도로 Chromium을 원격 디버깅 포트 9222에서 실행하고, 로컬 사이트를 켠 상태에서 실행합니다.

```sh
chromium --headless --no-sandbox --remote-debugging-port=9222 --user-data-dir=/tmp/hwp-browser-check about:blank
# Android/Termux에서는 실행 파일 이름이 chromium-browser입니다.
# 별도 터미널:
npm run test:browser
# 선택 인수: 사이트 URL, 미리 내려받은 샘플 폴더
node test/browser-check.mjs https://sihoo7005.github.io/hwp/ /path/to/samples
```

샘플 폴더를 생략하면 [rhwp v0.8.6의 공개 샘플](https://github.com/edwardkim/rhwp/tree/v0.8.6/samples)과 기존 공개 테스트 문서를 임시 폴더로 받습니다. 테스트 다운로드·스크린샷 위치를 출력합니다. 문서 원본과 샘플은 사이트 배포 산출물에 포함하지 않습니다.

2026-10-04: 자동 검사 17개와 Chromium 검증 통과. 실제 샘플의 그림·수식·도형·막대 차트, HWPX/HML/HWP3, 머리말 그림·각주 문서, 52쪽 표 문서의 쪽 이동, 암호 HWP3/HWP5/HWPX의 오입력과 재시도, 배포용 문서, 기존 치환·다운로드·재열기, 원본/결과와 보기 전환, 390px 화면의 너비 맞춤·확대를 확인했습니다. 샘플이 열리고 렌더링되는지 확인한 결과이며, 모든 쪽을 한글 원본과 픽셀 단위로 비교한 호환성 인증은 아닙니다.

## 배포와 고지

`npm run build`의 `dist/`를 GitHub Pages에 배포합니다. `.github/workflows/pages.yml`은 `main` 푸시 시 의존성 설치·검사·빌드 후, `PAGES_ENABLED=true`이면 Pages를 갱신합니다. [Actions 실행 결과](https://github.com/sihoo7005/hwp/actions/workflows/pages.yml)에서 상태를 확인합니다. 전체 계획은 [HWP_WEB_PLAN.md](./HWP_WEB_PLAN.md)에 있습니다.

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. CFB 처리는 `cfb 1.2.2`, 압축은 `pako 2.1.0`, 쪽 보기는 `@rhwp/core 0.8.6`을 사용합니다. 외부 의존성 고지와 [rhwp의 의존성 고지](./RHWP_THIRD_PARTY_LICENSES.md)는 빌드 시 `dist/THIRD_PARTY_NOTICES.txt`에도 포함합니다.
