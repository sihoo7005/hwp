# 모바일 한글 0.5.0

안드로이드용 네이티브 HWP 뷰어·에디터입니다.
Kotlin, Jetpack Compose, Android Canvas와 Rust 문서 엔진을 사용합니다.
앱 화면은 HTML이나 WebView를 사용하지 않습니다. 문서를 서버로 전송하지 않습니다.

APK는 `dist/`에 생성합니다. Android 8.0 이상 ARM64 기기를 대상으로 합니다.

## 지원 범위

| 형식 | 열기·페이지 표시 | 편집 | 저장 |
|---|---|---|---|
| HWP 3.x | 엔진이 해석하는 문서 | 보호되지 않고 변환 검사를 통과한 문서 | HWP 5 또는 HWPX |
| HWP 5.x | 일반 문서 | 일반 본문·표 셀·지원 개체 | HWP 5 또는 HWPX |
| HWPX | 일반 문서 | 일반 본문·표 셀·지원 개체 | HWP 5 또는 HWPX |

파일 메뉴에서 새 문서, 열기, 다른 이름으로 저장을 사용합니다.
문서의 글자를 누르면 안드로이드 입력기로 수정할 수 있습니다.
키보드의 Enter로 새 문단을 입력합니다.
입력 중인 내용은 적용하거나 취소할 수 있습니다.
편집·보기·입력·서식·표 메뉴를 가로로 이동해 사용합니다.
글자 서식, 문단 정렬, 표·수식·그림·사각형 삽입과 실행 취소·다시 실행을 지원합니다.
표의 행·열 추가·삭제와 셀 분할은 선택한 셀에서 사용합니다.
두 손가락으로 확대하고, 여러 쪽을 세로로 읽을 수 있습니다.
글꼴 파일을 추가하면 원본 글꼴로 표시할 수 있습니다.

저장은 새 파일을 만듭니다. 원본 파일을 자동으로 덮어쓰지 않습니다.
앱은 저장본을 다시 열어 본문과 표 셀의 텍스트를 확인합니다.
엔진이 내용 손실 가능성을 보고하면 저장을 중단하고 오류를 표시합니다.

문서는 32 MiB까지 읽습니다. 편집은 8 MiB·5천 문단·20만 글자까지 지원합니다.
암호 문서 열기, 보호 문서 편집, 기존 차트·그림·도형의 모든 속성 수정은 지원하지 않습니다.
옛 HWP3 형식으로 저장하는 기능은 없습니다.
대체 글꼴과 엔진이 지원하지 않는 개체 때문에 원본과 다르게 표시될 수 있습니다.
공식 한글 편집기의 모든 기능이나 픽셀 단위 표시 호환성을 검증한 제품은 아닙니다.

## 소스와 검증

앱 소스는 `android/`에 있습니다.
이 작업은 작업공간 인접 경로에 있던 네이티브 Android 소스를 바탕으로 구현했습니다.
문서 엔진은 MIT 라이선스 rhwp 0.8.7의 고정 커밋을 사용합니다.
검증 결과는 `dist/검증결과.md`에 기록합니다.

빌드 방법은 [android/README.md](android/README.md)를 확인하세요.
세 형식의 작은 검증 문서는 `tests/fixtures/`에 있습니다.
실제 JNI 검사 소스는 `tests/jni/com/sihoo/hwp/NativeReader.java`입니다.
