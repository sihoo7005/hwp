# HWP 텍스트 에디터 · 실험판

웹사이트: **[https://sihoo7005.github.io/hwp/](https://sihoo7005.github.io/hwp/)**

한글 문서의 본문을 직접 입력·삭제하고 새 파일로 저장합니다. 기존 단어 치환 화면을 텍스트 에디터로 바꿨습니다. 문서와 비밀번호는 브라우저 Worker 안에서 처리하며 외부 서버로 업로드하지 않습니다. `@rhwp/core 0.8.6` 문서 엔진을 사이트에 함께 배포합니다.

## 실행

Node.js 24와 Python이 필요합니다.

```sh
npm ci --ignore-scripts --no-bin-links
npm test
npm run build
npm run serve
```

**http://127.0.0.1:8765** 에 접속합니다. 파일 앱에서 HTML을 직접 열면 Worker/WASM이 실행되지 않을 수 있습니다.

## 편집과 저장

1. 일반 **HWP 5.0 또는 HWPX** 파일을 엽니다. 편집 가능한 문서는 **텍스트 편집** 보기로 열립니다.
2. 본문 문단을 클릭해 입력·삭제·붙여넣기합니다. 다른 글자 수, 공백·기호·이모지를 사용할 수 있습니다. 한글 조합 중에는 문서를 갱신하지 않으며, 조합 완료 후 입력을 반영합니다.
3. **쪽 보기**에서 배치를 확인합니다. 쪽의 본문을 클릭하면 해당 문단과 커서로 이동합니다. **전체 텍스트**에서는 표 셀 등을 포함한 텍스트를 읽고 복사합니다.
4. **실행 취소 / 다시 실행**은 문서의 최근 10단계 변경을 복원합니다. 입력 중에는 브라우저의 기본 텍스트 실행 취소도 사용할 수 있습니다.
5. **수정한 파일 저장** 또는 `Ctrl/Cmd+S`로 내려받습니다. 입력 반영을 기다리는 상태에서도 최신 입력을 먼저 반영합니다. HWP는 HWP, HWPX는 HWPX로 저장하며, 원본을 덮어쓰지 않습니다.

**Enter는 같은 문단 안에 줄바꿈을 넣습니다.** 문단 추가·삭제·합치기, 표 셀·그림·수식·글상자·머리말/꼬리말·각주 내부 편집과 서식 변경 도구는 아직 지원하지 않습니다. 표·그림 등의 개체가 있는 본문 문단은 보호하고, 같은 문서의 다른 일반 본문 문단은 편집할 수 있습니다.

첫 단계의 편집 범위는 **8 MB·5천 본문 문단·20만 글자**, 문단별 2만 글자입니다. 암호·배포용·전자서명·변경추적 등 특수 HWP, HWP3, HML은 보기만 지원합니다. 편집한 범위는 삽입 위치의 글자 서식을 이어받을 수 있으며, 문단 전체를 붙여넣는 등 넓은 범위를 바꾸면 내부 글자 서식이 단순화될 수 있습니다. 한 번의 변경에서 최초와 마지막 차이 사이를 바꾸고, 범위 밖의 텍스트·서식과 문서 개체를 보존합니다.

저장 시 엔진의 내용 손실 보고서를 검사하고 새 파일을 다시 열어 본문·전체 텍스트·구역/문단 수·개체 목록을 확인합니다. 손실 보고나 불일치가 있으면 다운로드를 중단합니다. 이 검사는 한글 프로그램의 호환성 인증이 아니므로 실제 한글에서 열기·배치·편집·재저장을 확인해야 합니다. 저장하지 않은 변경은 새 문서 열기와 페이지 종료 시 안내합니다. 현재 입력과 이력은 브라우저 메모리에 있으며 창을 닫거나 새로고침하면 복구되지 않습니다.

## 문서 보기

MIT **[@rhwp/core 0.8.6](https://github.com/edwardkim/rhwp/tree/v0.8.6)**의 그림·수식·도형·차트·표·다단·머리말/꼬리말·각주/미주·쪽 나눔 렌더링을 사용합니다.

| 형식 | 보기 범위 |
| --- | --- |
| HWP 5.0 | 일반·압축·비압축·배포용 |
| HWPX | ZIP/XML 문서, OWPML 구조 |
| 구형 HWP 3 | 읽기 지원. 모든 구형 문서의 재현 보장은 아님 |
| HML/HWPML XML | 엔진의 2.9/2.91 계열 지원 구조. 미지원 요소 안내 |
| 암호 문서 | HWP5 EncryptVersion 4, 압축 HWP3, ODF AES-256-CBC HWPX. 비밀번호 필요 |
| DRM·일부 구형 암호·손상 파일 | 미지원 안내 |

보기는 최대 **32 MB·5천 쪽**, 텍스트 20만 글자, 한 쪽 SVG 16 MB·16,384px까지입니다. 선택한 쪽만 이미지로 표시합니다. 처리 제한은 45초이며, 첫 로드에는 약 10 MB의 WASM 다운로드가 필요합니다. 비밀번호는 제출 후 비우고 저장하지 않습니다. 문서 텍스트를 HTML로 해석하거나 문서 스크립트를 실행하지 않습니다.

**모든 형식·개체를 100% 지원하지는 않습니다.** 대체 글꼴과 Worker의 글꼴 측정, 엔진 배치에 따라 원본과 줄바꿈·쪽 수가 달라질 수 있습니다. 특수 개체와 구형 형식의 일부 요소는 미지원입니다. 이전 자체 파서·치환기·HTML 뷰어는 회귀 검사를 위해 소스에 남아 있으며 현재 사이트의 편집에는 사용하지 않습니다.

## 검증

`npm test`는 기존 17개 검사와 텍스트 에디터 3개 검사를 실행합니다. 가변 길이·이모지·줄바꿈·탭 수정과 HWP/HWPX 재열기, 수정 범위 밖의 글자 서식·표 보존, 실행 취소·다시 실행·10단계 이력, 빈 문단 텍스트, 특수 문서 제한과 내용 손실 보고 시 저장 거절을 확인합니다.

브라우저 검사는 Chromium을 원격 디버깅 포트 9222에서 실행하고 로컬 서버를 켠 상태에서 실행합니다.

```sh
chromium --headless --no-sandbox --remote-debugging-port=9222 --user-data-dir=/tmp/hwp-browser-check about:blank
# Android/Termux의 실행 파일 이름은 chromium-browser입니다.
# 별도 터미널:
npm run test:browser
# 선택 인수: 사이트 URL, 미리 내려받은 샘플 폴더
node test/browser-check.mjs https://sihoo7005.github.io/hwp/ /path/to/samples
```

샘플 폴더를 생략하면 [rhwp의 공개 샘플](https://github.com/edwardkim/rhwp/tree/v0.8.6/samples)과 기존 공개 본문 테스트 문서를 임시 폴더로 받습니다. 문서 선택→직접 입력→조합 완료→커서 유지→실행 취소/다시 실행→저장→재열기, 여러 문단의 미반영 입력 저장, 쪽 클릭 편집, 보호 문서와 여러 형식의 렌더링, 암호 재시도, 390px 화면과 안전한 문자열 표시를 검사합니다. 실제 휴대폰 키보드의 모든 IME 동작과 모든 문서의 한글 호환성은 별도 검증이 필요합니다.

## 배포와 고지

`npm run build`는 `dist/`를 다시 생성합니다. `main` 푸시 시 GitHub Actions가 의존성 설치·검사·빌드 후 Pages에 배포합니다. [배포 상태](https://github.com/sihoo7005/hwp/actions/workflows/pages.yml), [개발 계획](./HWP_WEB_PLAN.md).

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. `cfb 1.2.2`는 HWP 보호 플래그 확인에, `@rhwp/core 0.8.6`은 보기·편집·저장에 사용합니다. 외부 라이브러리 고지와 [rhwp 의존성 고지](./RHWP_THIRD_PARTY_LICENSES.md)는 배포 파일에도 포함합니다. 원본 HWP와 참고 PDF, 테스트 샘플은 사이트 산출물에 포함하지 않습니다.
